# 方寸九宫：当前功能与复查记录

2026-09-23。本文描述正式小游戏当前行为；浏览器试玩与微信存档独立。

## 两种模式与道具

清雅庭院是不限时的无尽模式，保留行列九宫消除、连消、幸运方块和五张布局：方庭、石台、星位、长庭、曲院。各地图分别保存最高分、未完成棋局和好友排行。闯关成绩不进入庭院排行榜。

下表中的视频按钮仅在已配置广告位且平台支持时显示；当前版本只显示撤回。

| 位置 | 撤回 | 提示 | 复活 |
|---|---|---|---|
| 闯关对局顶部 | 直接撤回，逐步恢复历史 | 「提示 / 视频」按钮 | 不提供 |
| 庭院对局顶部 | 直接撤回最近一步 | 「提示 / 视频」按钮 | 不提供 |
| 闯关失败结算 | 可以撤回后继续 | 不提供 | 不提供 |
| 庭院失败结算 | 不提供 | 不提供 | 「复活 · 视频」，每局最多一次 |

撤回目前不需要广告。庭院撤回恢复棋盘、托盘、分数、能量和幸运奖励等状态，最近一步随存档保存；复活会清掉撤回记录，不能通过撤回重置复活次数。闯关撤回恢复步数、薄冰和目标，已通关的星级不回退。庭院仍按占用率、近期牌型和保底次数发牌，但每局随机状态已纳入存档和撤回。相同落子重放会得到相同的下一组牌、幸运方块和能量目标；旧存档迁移使用稳定种子。这里没有预先生成下一组，避免在尚未落子时提前决定盘面相关保底，因此本次不增加庭院下一组预告。闯关棋盘与发牌顺序固定。

视频提示只标出一块方块及其建议落点，不自动代放。闯关提示必须先在副本中验证完整通关路线；先尝试剩余参考路线和已验证路线，再进行有计算上限的搜索。无法在预算内证实可通关时，说明暂未找到可靠提示，不打开广告。拒绝提示不代表已经证明该局无解。庭院仍提供局部放置建议，不承诺无尽模式永久不失败。旧的静态专属攻略和失败自动提示仍已移除，基础拖放教学保留。

视频复活从现有棋盘中移除尽量少的普通方块，让当前托盘至少有一块可以放下；不改永久石障，不补分，不重发托盘。不提供免费复活；取消或播放失败不消耗复活次数。

## 广告配置与边界

奖励广告控制器已接入 `wx.createRewardedVideoAd`。只在发起播放后收到 `onClose` 且 `isEnded === true` 时兑现；提前关闭、结果缺失、加载或播放失败均不奖励。重复点击锁定，回调只处理一次；加载超过十秒会退出等待，播放期间不计这个加载超时。广告期间暂停游戏音频，界面输入锁定；返回后恢复。

`js/config.js` 的 `REWARDED_AD_UNIT_ID` 目前为空，需要填入账号下真实的激励视频广告位 ID。未配置广告位或平台没有广告 API 时，两个视频入口连同点击区域一起隐藏；撤回居中、结算分享按钮恢复全宽。接入代码保留，配置有效广告位后恢复入口，绝不会模拟广告完成。配置并上线前须用微信体验版检查实际播放、完整观看、提前关闭、无填充以及切后台的表现。测试中的广告回调仅在测试环境模拟，没有放进正式代码。

官方接口参考：[RewardedVideoAd.onClose](https://developers.weixin.qq.com/minigame/dev/api/ad/RewardedVideoAd.onClose.html)。

## 三章独立开放

第 1、13、25 关从首次启动即可体验，各章内部依次解锁。第一章学习行列与九宫；第二章加入薄冰，完成区域先破冰，再消除冰下方块；第三章叠加永久石障、窄缝和混合目标。它们共享摆放消除规则，属于机制递进。

每章各保留一局未完成棋局；切到其他章节再回来可以继续，首页记住上次游玩的章节。旧版单局存档迁入对应章节，既有星级保留。跨章进入下一关时也会优先恢复那一关已有的进度。单独完成第三章只提示本章完成，不误报三章全通；完成当前章后，首页主按钮引导选择章节。

共有 36 关、108 星，不限思考时间。参考步数以内三星，多一步两星，步数上限内成功为一星。参考解法证明可解，不代表唯一或最短解。前三关保留一落子教学，其余关卡不存在一步直接通关；本次没有再次调整难度或随机化关卡。

局内预告下一组三块及顺序，剩余步数不足以到达下一组时显示「本关最后一组」；顶部显示三星剩余步数。薄冰用裂纹预览，真正消除的格子用填充亮光预览。三星结算依次点亮，按钮无需等整个动画结束才能使用。

## 交互、存档与分享

按钮有按压缩放、颜色反馈与短导航过渡，移出按钮或取消触摸不会执行。锁定关卡会说明前置关卡。工具按钮在闯关和庭院使用同一位置，小屏也预留空间。按键和普通落子不逐次震动；消除等反馈遵守震动开关。

第一次新开庭院赠送两点初始能量，仅每个本地安装一次；正式充能仍为三点。满能量后常驻提示下一组领取幸运方块，实际发放时标记对应小块。

庭院保存棋盘、托盘和最近一步，复活次数随存档保留；闯关按每章保存落子历史，恢复时重放校验。损坏或规则不兼容的数据不会强套到新棋盘。第 18、24、33 关为规则版本 3，旧版未完成局需重开，已获星级保留。

存储读取异常可继续启动；写入失败保留各键最新快照，前台每五秒及切换前后台重试，不因回首页或换模式丢弃。未保存成功时显示对应提示。如果系统回收进程前一直无法写入，仍无法保留仅在内存中的进度。

庭院与闯关通关可分享成绩卡片，仅在玩家点击后调起微信分享，没有分享奖励。好友榜按地图分开，开放数据域待机轮询为 10Hz。

## 本次重制音效

| 事件 | 文件 | 时长 | 设计 |
|---|---|---:|---|
| 通关／刷新纪录 | win.wav | 1.12 秒 | 短上行旋律后落入柔和和弦，明确表达达成 |
| 本局结束／闯关失败 | over.wav | 0.60 秒 | 下行木质音，轻收束，不用刺耳警报 |
| 破冰 | ice.wav | 0.24 秒 | 短促碎裂与细小余振，和普通消除区分 |

三段均为 44.1kHz、16 位、单声道 WAV，首尾渐隐，无削波。音效事件、开关和切后台停止逻辑均保留。背景音乐文件、音量和循环方式完全不变；背景文件 SHA1 为 `a122d1fa2322749f61db14c3943abb35c3b8c033`。

本地试玩页右侧「分别试听全部九种音效」可以播放实际素材，也提供同一操作序列的修改前后对比。自动检测只能验证音频格式和电平，真实手机的听感、扬声器音量和蓝牙延迟仍需试听确认。

## 全部音效协调复查（2026-09-23）

以已经认可的通关、结束声音为基准，统一短音效的起音和音色层次：

- 按钮与落子：改为轻木音，起音渐入，按钮比落子更轻。游戏内落子瞬间峰值由约 −14.1dBFS 降至 −22.9dBFS，50ms 峰值响度仅降低约 1.8dB，主要收住尖峰而非一味变小声。
- 撤回：换成 210ms 下行木音，和结束音构成相近的音色；旧素材起点不为零的问题也随之消除。
- 连消：旧素材为多音和弦，整体升调时会出现 D 大调外的音；改为 D 基音加八度，四档依次落在 D/E/F#/A，保留递进感。
- 破冰：保留碎裂和短余振，收窄噪声频段；同一频谱检测口径下，3.5kHz 以上的能量占比从约 42.6% 降为 8.4%。它仍比木音明亮，方便识别事件。
- 普通消除、充能、通关、结束：文件保持不变，已经与统一方向协调，无需全部重做。

九种音效均通过格式、首尾波形、峰值和混音检查；按钮→落子→消除→通关的响度层次有断言检查。播放事件回归覆盖四档连消、充能与结算恢复原速、静音以及切后台停止。此轮未修改游戏规则，不重复以大规模玩法模拟代替音频检查。

另生成《庭间慢步》背景备选：约 21.82 秒、88 BPM、疏落木音与柔和和声，无鼓点。使用同一组新音效提供搭配试听。它仅存于 `docs/previews/audio-review/garden-bgm-proposal.wav`，不随小游戏打包，不修改正式背景音乐的路径、音量和循环方式。原背景保持可用，是否采用备选以实际试听和连续游玩疲劳感为依据。

音效前后比较使用相同操作序列、相同原背景与统一试听增益；不要把单独打开原始音效的最大音量当作游戏里的实际音量。试听页同时只播放一个播放器，避免误以为多轨叠播是素材问题。

复现音频验证与生成备选：

```sh

python3 tests/build-audio-review.py
node tests/game-feedback.test.js
node tests/build-playable-preview.js
```

## 自动检查与可玩性结论

- 36 关参考解全部三星通关，提示沿参考路线也能完成全部关卡。
- 闯关 7,200 局随机模拟、68,540 次落子，检查撤回、存档、薄冰、永久障碍、非法落子与步数终止。
- 庭院 3,000 局、102,251 次落子，覆盖三种策略和五张地图，检查非法落点、触摸取消、多指、切后台、输入锁和存档。补充检查每个终局的复活方案确实能打开合法落点，且不改动原盘面或永久障碍。
- 新道具测试覆盖真实按钮分发、广告缺少配置、取消、异常、过早回调、重复点击、完整观看、奖励去重、一次复活、重启后的撤回与复活次数。
- 章节测试覆盖首关独立开放、章内锁定、独立存档、跨章恢复、后章星级保存、单章完成提示与全章完成区分。
- 四种手机尺寸的按钮、棋盘、章节网格和托盘布局检查；音效、静音、分享卡片、好友榜与存储故障重试有回归检查。

自动模拟用于发现状态与规则问题，不等同于真人通关率或「没有任何 bug」。现阶段的关卡可解且机制逐章增加，独立开放更方便体验；难度是否有趣仍需真实试玩。建议重点观察玩家第二、三章首关是否理解破冰和石障，以及视频提示后是否能继续推进。先用少量真实玩家观察完成率和退出位置，再调关卡；不依据随机机器人胜率直接判断难度。

## 上线前漏洞修复与复查

2026-09-23 本轮修复：撤回刷牌、未配置广告位仍有入口、闯关贪心提示失误、目标与圆石叫法冲突。另修正读取到负数或无穷大历史最高分时的显示和计分污染。

目标统一叫「标记」，目标卡片和棋盘复用 › 图案；冰下目标仍用 2 表达两次处理，说明写明「› 是目标 · 2 先破冰 · 圆石不可清除」。破冰播放音量从 0.34 调至 0.48（约 +3dB），50ms 峰值约 −28.6dBFS，比普通消除低约 2.6dB，保留短碎裂音色。背景音乐文件及其播放设置未变。

验证结果：

- 五张地图分别反复撤回并重放同一步 40 次，发牌和随机状态完全一致；中途退出重启后也一致。
- 额外 40 次重放充满能量的一步，新能量目标与幸运方块一致；旧存档可稳定迁移，损坏随机状态被拒绝。
- 36 关参考解提示全部可以通关；33 个通过交换独立落子得到、另行验证可解的偏离局面，全部获得验证通过的完整路线。
- 104 个随机偏离的未结束局面中，9 个找到并重放验证了完整路线；其余 95 个拒绝提示。该组没有证明每个被拒绝的局面无解，也不代表真实玩家通关率。
- 7,200 局闯关模拟（68,540 次落子）、3,000 局庭院模拟（102,251 次落子）通过。庭院报告见 `docs/stress-release-review-2026-09-23.json`。
- 功能回归覆盖全部音效、广告完整观看/取消/失败、自动存档、章节进度、分享、好友榜、小屏布局及输入取消。

现在可以发布没有视频道具入口的版本；是否可开通广告以账号后台为准。腾讯广告 2024 年的[小游戏专场培训资料](https://training.tencentads.com/uploads/202406/p3QdnttL_FhMfKa.pdf)列出累计 UV >500 且无刷量/严重违规这一条路径，也列出同公司主体已有合资格小游戏的路径；不能把它解释成所有账号只有一种开通方式，或用旧培训资料代替当前后台资格。
