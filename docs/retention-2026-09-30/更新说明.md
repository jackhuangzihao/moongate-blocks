## 玩家能看到的变化

- 新玩家首次走进庭院，会看到一个只差三格的目标宫。沿虚线落子就能完成消除、充满能量，下一组立即出现带金色标记的幸运小块，并解锁修竹。随后直接自由摆放。教学预填棋盘不增加分数或排行榜成绩；教学可存档恢复，不向已有成绩或进度的玩家强插教学。
- 普通引导在真正完成一次消除后才结束。点击托盘、取消拖动、放错位置，或只完成一次未消除的放置，不会提前结束引导。
- 花木累计消除门槛改为修竹 1、梅花 20、荷花缸 80、古松 200。陈设仍按 12、36、72、108 星解锁。原有累计进度和星级保留，符合新门槛的物件直接解锁。
- 「我的庭院」卡片可以点选摆放／收起；收起不扣进度，首页、结算插画、庭院分享图均使用当前摆放选择。未解锁卡片会说明还差多少进度。
- 庭院结算展示本局累计消除和下一件收藏目标。撤回会同步回退本局与累计消除进度。
- 闯关失败后反复撤回、重复失败，同一次尝试只计一次失败。撤回后保存再恢复仍保留这一标记；重新挑战才是新尝试。
- 提示若需要撤回多步，会先说明需要退回几步，并允许取消。取消不会消耗免费提示，也不会开始广告。没有配置广告位时仍隐藏视频入口，没有新增免费复活。
- 不推进目标的普通消除改为提示“腾出空间了”，避免把每一次消除都说成目标进度增加。
- 音效和背景音乐未修改。今日庭局暂未加入。

## 后台自定义分析需要配置

代码沿用 `wx.reportEvent`，新增下列事件。需在微信小游戏后台创建同名事件和字段；本次没有操作后台，无法确认是否已经配置成功。

以下所有新事件的公共字段：`mode`（字符串，challenge 或地图 ID）、`level_id`（数字，闯关 1–36／庭院 0）、`pieces`（数字，当前放置次数）。

| 事件名称 | 额外字段 | 含义 |
|---|---|---|
| session_start | entry 字符串：new / resume | 新局／新尝试开始，或从存档继续；撤回不算新局 |
| first_place | 无 | 当前本地数据首次成功放置 |
| first_clear | 无 | 当前本地数据首次完成区域消除 |
| first_lucky | 无 | 当前本地数据首次实际领取幸运方块，非仅充能 |
| session_exit | reason 字符串：home / restart | 未结束时主动返回首页或确认重开 |
| session_pause | reason 字符串：background | 未结束时切后台；广告／提示确认过程中不计 |

现有 `level_result`、`hint_used`、`garden_result` 继续使用。

- `level_result` 的 fail 现在每次独立尝试最多上报一次；之后撤回并成功仍可上报 win。因此不能把 win/(win+fail) 直接当作“独立尝试通过率”。
- 新增首次事件以本地存储去重；清除数据、换设备会重新计数。它不是跨设备用户身份识别。
- 切后台只代表暂停，不能直接当作流失。系统强制回收不保证执行任何回调，因此不能据此声称覆盖所有离开行为。
- 可先看开始→首次落子→首次消除→首次幸运奖励，以及新局开启次数；结合平台已有的次日留存与真实用户反馈评估。程序模拟不能替代真实留存数据。
