## 固定检查

沿用现有入口，无需安装依赖：

```sh
node tests/run.js
```

入口自动发现全部 `*.test.js` 文件，每组独立进程运行，以下两组已自动包含：

```sh
node tests/module-structure.test.js
node tests/playable-startup.test.js
```

- **模块结构**：检查主入口、全部 `js` 模块、配置指定的开放数据域脚本的语法、引用目标、路径大小写和循环依赖。检查器包含缺失模块、错误大小写、循环、语法错误等失败样本。
- **引用约定**：静态检查针对当前的字面量相对 CommonJS `require` 写法；动态引用或第三方包会要求显式处理。它不是完整 JavaScript AST 分析器，未来引入新的模块语法时须一起评估检查器，不能直接关闭断言。
- **完整试玩启动**：从当前源码在系统临时目录重新生成页面，再以模拟 DOM、Canvas、存储执行生成的脚本。覆盖首页、小屏、闯关试验室、每日和落玉庭五种入口，检查输入监听、首帧绘制、状态文字和选关列表。另有缺失共享配置模块的失败样本。
- 新的试玩测试不修改项目中的生成页面，不访问微信 API、网络、真实广告或用户存档；无论通过或失败，都会清理自己创建的临时目录。
- 模拟画布只验证绘制调用及页面启动，不检验真实像素、音效、浏览器排版或手机表现，不能代替真机验收。
