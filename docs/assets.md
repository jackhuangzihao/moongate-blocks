`tests/build-result-sounds.py` 可合成部分现用音效；它不重建全部音乐与音效，也不应为验证素材来源而直接在开发目录执行，因为会覆盖音频文件。`tests/build-audio-review.py` 是试听对比工具，使用额外 Python 库，不是运行游戏或执行 Node 全量测试的前置步骤。

项目现有许可见根目录 `LICENSE`。这份记录不改变许可选择，也不替代生成平台的使用条款。后续加入第三方代码、字体、图片或音频时，应先确认来源和允许用途，保留所需署名及第三方许可，不直接套用项目许可。

建议将生成订单、平台条款快照等证明留在个人备份中；含账号、付款信息或提示词私有资料的原始记录不必公开。公开清单只保留可核实、适合分享的信息。
